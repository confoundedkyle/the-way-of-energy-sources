# The Way of Energy sources

Everybody’s generating. Show me the grid.

296 documented sources · 132 registered 2026 sources · 162 screened exclusions or nonselections · 1778 encountered URLs in the companion discovery log.

Start with [the full bibliography](SOURCES.md), or download the [APA-style PDF](The_Way_of_Energy_APA_Sources.pdf).

This companion contains the documented source record behind Kyle Byrd’s article, including sources omitted from the narrative and sources screened but excluded. Unresolved authors, titles and dates are flagged. Screened exclusions remain separate from qualifying evidence. Search-log URLs are not described as fully reviewed articles.

## Corrections

Please include the source ID, original URL, and the correction or additional evidence. The publication window for the mapped research is January 1–October 29, 2026. A 2026 publication may describe earlier work. Employer and vendor claims are not independently validated outcomes.

## Publication note

The source research repository is private. This companion is published in a separate public repository; it contains bibliographic metadata, brief audit notes and source mappings, not the private repository or full copyrighted articles.
